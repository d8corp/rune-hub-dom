Welcome to Rundom

@rundom/core is a lightweight frontend framework with fine-grained reactivity, JSX, and direct DOM manipulation. Built for speed, designed for elegance.

Get Started View on GitHub
⚡

No VDOM

Direct DOM updates without virtual tree diffing overhead

📦

~3KB gzipped

Ultra-lightweight core that ships minimal bytes

🔥

Fine-grained

Reactive signals update only what changed

App.tsx 
// Rundom — reactive by default
import { createSignal, render } from '@rundom/core'

function Counter() {
  const [count, setCount] = createSignal(0)

  return (
    <button onclick={() => setCount(count() + 1)}>
      Count: {count}
    </button>
  )
}

render(<Counter />, document.body)
